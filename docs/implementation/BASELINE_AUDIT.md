## 风险与问题识别
1. **权限风险**: 部分API接口未严格校验用户归属，存在IDOR风险
2. **数据持久性**: PDF、数据集等文件未持久化到对象存储，仅保存在内存/临时目录
3. **可靠性**: 缺乏统一错误处理、超时、重试机制
4. **可观测性**: 缺乏监控、日志、用量统计
5. **安全**: 缺乏输入校验、CSRF防护、XSS防护等安全措施
6. **部署**: 构建脚本包含生产数据库迁移，存在风险
