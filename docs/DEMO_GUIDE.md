# 演示指南 (DEMO_GUIDE.md)

本文档介绍如何使用 SOLVER AI 的演示模式，快速体验所有功能。

## 一、快速开始
### 1. 访问演示地址
- 官方演示地址：`https://solver-ai-sand.vercel.app`
- 备用演示地址：`[待补充]`

### 2. 进入演示模式
访问演示地址后，点击首页的「演示体验」按钮，系统会自动创建演示用户并登录，无需注册。

### 3. 演示账号说明
- 演示用户为只读权限，无法进行数据修改、删除、上传等操作
- 演示用户预置了完整的测试数据，包括错题本、文献、数据集、实验记录等
- 演示会话有效期为2小时，到期后自动失效

## 二、功能体验指引
### 📚 复习助手模块
1. 点击左侧导航栏的「复习助手」
2. 查看预置的高等数学错题本，包含错题、知识点关联、复习计划
3. 体验AI错题解析功能，点击错题下方的「AI解析」按钮
4. 查看智能生成的复习计划，根据错题情况推荐复习重点

### 📑 文献研究模块
1. 点击左侧导航栏的「文献研究」
2. 查看预置的人工智能相关论文列表
3. 点击任意论文查看详细信息，包括摘要、关键词、引用格式
4. 体验文献语义搜索功能，在搜索框输入关键词查找相关文献
5. 尝试AI文献问答功能，点击「提问」按钮，询问关于论文的问题

### 📊 数据洞察模块
1. 点击左侧导航栏的「数据洞察」
2. 查看预置的学生成绩数据集、销售数据集
3. 点击数据集查看自动生成的统计分析报告
4. 体验可视化分析功能，选择不同图表类型查看数据分布
5. 尝试AI数据解读功能，点击「AI解读」按钮获取数据分析建议

### 📓 实验台账模块
1. 点击左侧导航栏的「实验台账」
2. 查看预置的大学物理实验、化学实验记录
3. 查看实验步骤、数据记录、结果分析
4. 体验实验数据版本管理功能，查看历史版本对比
5. 尝试AI实验建议功能，点击「AI建议」获取实验优化建议

### 🔬 原理实验室模块
1. 点击左侧导航栏的「原理实验室」
2. 选择感兴趣的课程原理，例如「算法可视化」、「电路仿真」
3. 交互式体验原理演示，调整参数观察变化
4. 查看步骤化原理推导过程，加深理解
5. 尝试AI答疑功能，询问关于原理的问题

### 💼 求职助手模块
1. 点击左侧导航栏的「求职助手」
2. 查看预置的简历模板和优化建议
3. 体验面试题库功能，按岗位类型筛选面试题
4. 练习编程题目，查看AI解答和思路讲解
5. 查看职业路径推荐，根据专业和兴趣推荐适合的岗位

## 三、核心功能演示
### 1. AI 问答功能
在任意模块中，你都可以使用AI问答功能：
- 文献问答：针对上传的文献内容提问，获取精准回答
- 数据问答：针对数据集提问，自动进行统计分析
- 学习问答：针对知识点提问，获取详细讲解
- 实验问答：针对实验问题提问，获取解决方案

### 2. 文件解析功能
在演示模式中，你可以查看系统已经解析好的文件：
- PDF文献解析：自动提取标题、摘要、关键词、参考文献
- 表格文件解析：CSV/Excel自动解析，推断字段类型，生成统计信息
- 图片文件解析：OCR识别文字内容（如果配置了相关服务）

### 3. 项目空间功能
点击左侧导航栏的「我的项目」，查看演示用户的项目空间：
- 每个项目包含独立的文献、数据集、实验记录
- 项目任务管理，查看TODO列表和完成进度
- 资源关联，查看项目下的所有相关资源

## 四、演示限制说明
为了保证演示环境的稳定，演示用户有以下限制：
1. **只读权限**：无法创建、修改、删除任何数据
2. **功能限制**：无法上传文件、无法调用付费AI接口
3. **会话限制**：演示会话有效期2小时，到期自动清除
4. **速率限制**：AI问答功能有调用频率限制，每分钟最多3次

## 五、本地部署演示
如果你想在本地部署演示环境，可以按照以下步骤操作：

### 1. 安装依赖
```bash
npm install
```

### 2. 配置环境变量
复制 `.env.example` 为 `.env`，至少配置以下变量：
```env
DATABASE_URL="postgresql://user:password@localhost:5432/solver_db"
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="your-secret-key"
```

### 3. 初始化数据库
```bash
npx prisma migrate dev
```

### 4. 启动开发服务器
```bash
npm run dev
```

### 5. 初始化演示数据
访问 `http://localhost:3000/api/auth/demo-login`，系统会自动创建演示用户和测试数据。

## 六、常见问题
### Q: 演示模式的数据是真实的吗？
A: 演示模式的数据都是模拟生成的测试数据，仅用于功能演示，不涉及真实用户信息。

### Q: 我可以保存演示中的数据吗？
A: 演示模式为只读权限，无法保存数据。如果需要使用完整功能，请注册正式账号。

### Q: 演示环境的AI功能有限制吗？
A: 是的，演示环境的AI功能有调用频率和配额限制，如果需要无限制使用，请部署私有版本。

### Q: 演示环境的功能和正式版本有区别吗？
A: 演示环境包含正式版本的所有核心功能，仅限制了写入操作和AI调用配额。

### Q: 我可以在演示环境中测试文件上传功能吗？
A: 演示环境不支持文件上传功能，如果需要测试该功能，请部署本地版本。
